# legacy — 초기 카카오톡 봇 버전 (보관용)

이 폴더는 프로젝트 **초창기**의 카카오톡 단톡방 봇 구현을 보관합니다.
현재 이 프로젝트는 **웹 RPG(`ganghwa-rpg`)** 로 방향이 바뀌었고, 실제 개발/배포는
[`web/`](../web) 에서 이뤄집니다. 아래 파일들은 더 이상 사용되지 않아요.

- `main.js` — 안드로이드 **메신저봇R** 용 단일 스크립트 (카톡 단톡방에서 채팅으로 플레이)
- `SETUP.md` — 그 카톡 봇 설치 가이드

> 카카오톡 일반 단톡방은 공식 봇 API가 없어 24시간 켜진 안드로이드 환경이 필요했고,
> 그 부담 때문에 브라우저로 즐기는 웹 버전으로 전환했습니다. 규칙(강화/파괴/사냥 등)의
> 원형은 여기서 시작됐지만, 현재 밸런스·기능은 `web/game.js` 가 최신입니다.
