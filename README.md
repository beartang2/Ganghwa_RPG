# 카카오톡 단톡방 확률 RPG 강화게임 봇 ⚔️

카카오톡 **단톡방(그룹채팅)**에서 다같이 즐기는 **확률 RPG 강화게임** 봇입니다.
[메신저봇R](https://play.google.com/store/apps/details?id=com.xfl.msgbot) 기반으로,
안드로이드 공기계가 없어도 **PC 에뮬레이터**에 올려서 쓸 수 있습니다.

## 게임 규칙

- **강화**: `강화` 한 번이면 끝! **골드를 소모**하며, 단계가 오를수록 성공률은
  낮아지고 **파괴 확률과 비용이 높아집니다.** 파괴되면 **+0으로 리셋** → 처음부터 다시! 😱
- **골드**: 신규 1,000G로 시작. `출석`으로 하루 1회 +1,000G 획득.
  골드가 떨어지면 강화를 못 하니 출석·싸움으로 벌어야 합니다.
- **싸움(PvP)**: `싸움 상대이름` 으로 결투 신청. **이기면 상대 골드의 20%를 뺏습니다.**
  강화 수치가 높을수록 유리하지만 **하극상**도 가능. **하루 5회 제한.**
- **강화로그 / 오늘의 호구**: 최근 강화·싸움 기록을 남기고,
  **오늘 제일 많이 깨진 사람**을 `오늘의호구`로 공개합니다 🤡
- **저장**: 기록은 파일에 저장되어 봇을 껐다 켜도 유지됩니다. (**방마다 독립된 게임**)

## 명령어

| 명령어 | 설명 |
|--------|------|
| `도움말` | 명령어 목록 |
| `강화` | 무기 강화 (골드 소모, 실패 시 파괴될 수 있음!) |
| `출석` | 하루 1회 골드 받기 (+1,000G) |
| `내정보` | 내 무기 · 골드 · 전적 확인 |
| `싸움 [상대이름]` | 결투 신청 — 이기면 상대 골드 20% 획득 (하루 5회) |
| `랭킹` | 이 방의 강화 순위 TOP 10 |
| `강화로그` | 최근 강화/싸움 기록 |
| `오늘의호구` | 오늘 제일 많이 깨진 사람 🤡 |
| `강화확률` | 단계별 성공/파괴 확률·비용표 |

### 강화 확률 (성공 / 파괴)

| 단계 | 성공 | 파괴 |
|------|------|------|
| +0~2 | 95% | 0% |
| +3~5 | 80% | 0% |
| +6~8 | 65% | 5% |
| +9~11 | 50% | 10% |
| +12~14 | 35% | 17% |
| +15~17 | 25% | 25% |
| +18~20 | 15% | 35% |
| +21~ | 8% | 45% |

> 실패는 무기 유지(단, +10 이상은 1단계 하락), **파괴는 +0으로 리셋.**
> 무기 등급: 나무막대기 → 청동검 → 강철검 → 기사검 → 미스릴검 → 용검 → 전설의검 → 신의검

## 빠른 시작

1. 안드로이드(공기계 또는 **PC 에뮬레이터**)에 **메신저봇R** 설치
2. 봇 전용 카카오 계정으로 로그인 → 단톡방에 초대
3. 메신저봇R에서 새 봇 생성 → `main.js` 내용 붙여넣기 → 컴파일 → ON
4. 단톡방에서 `강화` 입력해서 시작!

> ⚠️ 카카오톡 일반 단톡방은 공식 봇 API가 없어, **카톡에 로그인된 안드로이드 환경이 24시간 떠 있어야** 봇이 동작합니다.
> 자세한 설치·배포는 **[docs/SETUP.md](docs/SETUP.md)** 참고.

## 밸런스 / 명령어 튜닝

`main.js` 안에서 조절할 수 있습니다.
- 강화 난이도: `odds()` 함수의 확률 값
- 강화 비용: `enhanceCost()` 공식
- 골드 설정: `CONFIG.startGold` / `attendGold` / `stealPct`
- 무기 이름/등급: `TIERS` 배열
- 하루 싸움 횟수: `CONFIG.dailyFights`
- PvP 밸런스: `cmdFight` 의 `pWin` 공식
- 새 명령어 추가: `main.js` 하단 "튜닝 가이드" 주석 참고
