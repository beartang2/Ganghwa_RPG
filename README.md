# 강화 RPG (ganghwa-rpg) ⚔️

다같이 아무 생각 없이 **무기를 강화**하고, 깨지면 처음부터 다시 하는 **확률 RPG 웹게임**.
브라우저로 접속해서 함께 즐깁니다.

▶️ **플레이: https://ganghwa.beartanh.dev**

> 초창기엔 카카오톡 단톡방 봇이었지만 지금은 **웹 게임**으로 전환했어요.
> 옛 카톡 봇 구현은 [`legacy/`](legacy) 에 보관돼 있습니다.

## 🎮 무엇을 하나

- ⚒️ **강화** — 골드로 무기 강화(+0~99). 로스트아크식으로 고레벨일수록 성공률이 급감하고
  대부분 **실패**. 실패가 쌓이면 🔨**장인의 기운**이 차고 100%면 **확정 성공**.
  💥**파괴되면 한 단계 뒤로**(등급 바닥 또는 −15레벨 중 높은 쪽) — 🛡️방지권으로 방어(하루 3개 구매 제한, 나머지는 사냥 드랍).
- 🌈 **초월** — +99 도달 후 재료(💠사냥 파편 · 🌟레이드 정수)를 모아 초월하면 무기가 +0 으로
  돌아가고 영구 **★**을 얻어요. ★1부터는 방지권이 통하지 않습니다.
- ✨ **직업** — 근딜(검)·원딜(활)·탱커(방패)·힐러(지팡이). 레이드에서 역할이 다름.
- 🔥 **무기 속성** — 불·물·대지·바람·번개·얼음·빛·어둠·독 9종(랜덤). 등급·속성별 이미지.
- 💰 **골드 수급** — 출석 / 🗡️사냥(하루 20회 + 이후 ♾️무한 사냥) / ⛏️**채굴장**(기력 관리형
  곡괭이질·노다지·숙련도) / ⚔️싸움 승리(상대 골드 약탈).
- 🐲 **파티 레이드** — 파티를 만들어 초대·수락하고 보스 처치. 전투를 타임라인으로 다같이 관전.
- 🎒 **인벤토리** — 10칸 시작(칸당 999개 스택 — 칸은 아이템 *종류* 수로 찬다). 상점 확장 패키지(1회) +4칸, 배틀패스 프리미엄 Lv.15 +4칸 → 최대 18칸.
  방지권·부스트권·염색약·초월 재료·상자 열쇠·마석이 전부 여기로.
- 🛒 **상점** — 아이템을 인벤토리로 지급. 염색약은 가방에서 '사용하기'로 발동. (직업 변경권은 판매 종료 — 장비 칸으로 대체)
- 🗡️ **장비 칸** — 무기를 직업당 한 자루씩 최대 4자루. 무기마다 강화·★·속성·장인의 기운이 따로이고,
  장착한 무기가 직업을 정한다. 칸은 💎 프리즘 상점(100 → 150 → 200💎). 랭킹은 가장 좋은 무기 기준.
- 💎 **프리즘** — 골드와 별개인 두 번째 재화. 확률표를 화면에 그대로 공개한다.

  | 얻는 곳 | 방법 | 기대값 |
  |---|---|---|
  | 📦 상자 | 🗝️ 상자 열쇠(사냥 드랍) 1개로 상자 3개 중 하나 선택, 나머지 둘 내용도 공개 | 열쇠당 💎1.15 |
  | ⚗️ 연금술 | 🔮 마석(사냥 드랍) + 골드. 약불(5+2만G)·중불(15+10만G)·강불(40+40만G) | 💎1.05 · 4.05 · 12.55 |
  | 🧸 캡슐 | 골드만(1회 3만G, 10연 가능, 무제한). 골드 환급·마석도 나옴 | 회당 💎0.74 |

  프리즘 상점: 🗡️ 장비 칸 +1 · 🌈 무지개 염색약 60 · 🔨 장인의 망치 8(장인의 기운 +50%) · 🎁 초월 꾸러미 25(파편 30 + 정수 3).
  열쇠·마석은 무한 사냥에서도 나오지만 확률이 낮다(열쇠 6% → 1.5%, 마석 45% → 12%).
- 🏅 랭킹 / 💰부자 / 🕯️추모(오늘 무기가 많이 깨진 사람) / 📜로그.

## 🚀 실행 / 배포

게임은 전부 [`web/`](web) 에 있고, **두 가지로 띄울 수 있어요**:

| 방식 | 설명 | 가이드 |
|------|------|--------|
| **로컬/상시 서버** | 맥·PC를 Node 서버로 (`node server.js`), 같은 네트워크에서 접속. SQLite 저장. | [`web/README.md`](web/README.md) |
| **Vercel + Supabase** | 서버리스 + 관리형 Postgres 로 공개 URL 호스팅. | [`web/VERCEL-MIGRATION.md`](web/VERCEL-MIGRATION.md) |

빠른 로컬 실행:
```bash
cd web
npm install
npm start        # 또는 npm run dev (nodemon)
# 터미널에 뜨는 http://<로컬IP>:3088 주소를 공유
```

## 🎨 화면 / 이펙트

대장간 테마(그을음·무쇠·놋쇠·쇳물). 빌드 없는 바닐라 JS 를 유지하려고 [React Bits](https://reactbits.dev) 컴포넌트를
`web/public/fx.js` 로 이식했다 — 원본 알고리즘·셰이더는 그대로, React 훅만 일반 객체로 바꿨다.

| 원본 (React Bits) | 쓰는 곳 |
|------|------|
| Particles | 화면 아래에서 떠오르는 화로 불씨 (`#embers`) |
| ClickSpark | 강화·사냥·채굴·레이드 탭 불꽃, 강화 결과 버스트 |
| StarBorder | 강화 버튼 테두리 빛 |
| ElectricBorder | 장인의 기운 100%(다음 강화 확정)일 때 화로 패널 |
| GradientText | 전설·초월 무기 이름 |
| ShinyText | 로그인 타이틀 |
| Counter | 상단 골드 숫자 |

`fx.js` 로드 실패나 WebGL2 미지원이면 해당 효과만 빠지고 게임은 그대로 동작한다. `prefers-reduced-motion` 을 존중한다.

### 무기 그림 (`web/public/weapon-art.js`)

180장을 그리는 대신 부품을 겹쳐 그린다 — **형태는 직업**(검·활·방패·지팡이), **금속은 등급**
(무쇠 → 푸른 강철 → 흑강+자수정 → 황금 → 결정), **속성은 기호 대신 재질과 현상**으로 드러낸다.

| 속성 | 금속·결정 표면 | 나무 부분(일반 방패·낮은 등급 활대·지팡이 자루) | 둘레 효과 |
|---|---|---|---|
| 불 | 식은 쇳물 + 빛나는 균열 | 그을림 + 불씨 | 위로 피어오르는 불꽃 |
| 물 | 물결 빛 + 파문 + 광택 | 물먹은 결 + 물방울 | 맺혀 떨어지는 물방울 |
| 대지 | 판석(방패) · 화강암 결 · 정동(보주) | 진흙 + 자갈 | 떠다니는 돌조각 |
| 바람 | 소용돌이 결 + 잎 | 바람 긁힘 + 잎 | 휘감는 바람결 |
| 번개 | 먹구름빛 + 갈라지는 번개 · 플라스마(보주) | 벼락 자국 | 튀는 번개 |
| 얼음 | 깎인 결정면 + 서리꽃 | 서리 | 고드름 · 결정 |
| 빛 | 퍼지는 광휘 | 볕에 바램 + 새는 빛 | 반짝임 · 광선 |
| 어둠 | 별 박힌 성운 + 새는 균열 | 썩음 + 보랏빛 실핏줄 | 피어오르는 그림자 |
| 독 | 거품 + 부식 + 흘러내리는 진액 | 독 곰팡이 | 떨어지는 독방울 |

재질은 일반 등급부터 은은하게 깔리고 등급이 오를수록 진해진다. 활은 화살촉에도 속성 현상이 실린다(희귀부터).
등급이 오를수록 가드가 날개·후광으로 커지고, 전설부터는 둘레 효과가 움직인다.

```js
WeaponArt.svg({ cls: 'warrior', element: 'fire', grade: 'legend' })  // → '<svg …>'
```

직접 그린 PNG 를 쓰고 싶으면 `app.js` 의 `USE_WEAPON_PNG = true` (규칙은 [`web/public/weapons/README.md`](web/public/weapons/README.md)).
일부만 있으면 화풍이 섞이니, 한 직업 분량을 다 채웠을 때 켜는 걸 권장.
