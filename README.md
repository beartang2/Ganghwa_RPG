# 카카오톡 단톡방 게임봇 🎮

카카오톡 **단톡방(그룹채팅)**에서 돌아가는 게임 봇입니다.
[메신저봇R](https://play.google.com/store/apps/details?id=com.xfl.msgbot) 기반으로,
안드로이드 공기계가 없어도 **PC 에뮬레이터**에 올려서 쓸 수 있습니다.

## 기본 게임

| 명령어 | 설명 |
|--------|------|
| `도움말` | 지원 명령어 목록 보기 |
| `가위바위보 [가위\|바위\|보]` | 봇과 가위바위보 대결 |
| `주사위 [면수]` | 주사위 굴리기 (기본 6면) |
| `로또` | 로또 번호 6개 추천 |
| `숫자게임` | 1~100 숫자 맞히기 (업/다운) |

> 접두사 없이 바로 `주사위` 라고 입력하면 반응합니다.
> 오작동이 잦으면 `main.js` 의 `CONFIG.prefix` 를 `'!'` 나 `'/'` 로 바꾸세요.

## 빠른 시작

1. 안드로이드(공기계 또는 **PC 에뮬레이터**)에 **메신저봇R** 설치
2. 봇 전용 카카오 계정으로 로그인 → 단톡방에 초대
3. 메신저봇R에서 새 봇 생성 → `main.js` 내용 붙여넣기 → 컴파일 → ON
4. 단톡방에서 `도움말` 입력해서 동작 확인

> ⚠️ 카카오톡 일반 단톡방은 공식 봇 API가 없어, **카톡에 로그인된 안드로이드 환경이 24시간 떠 있어야** 봇이 동작합니다.
> 자세한 설치·배포 방법은 **[docs/SETUP.md](docs/SETUP.md)** 참고.

```
├── README.md        # 이 문서
└── docs/
    └── SETUP.md     # 설치 · 배포 상세 가이드
```

## 게임 추가하기

`main.js` 하단의 **"게임 추가하는 법"** 주석을 참고하세요. 게임 객체 하나를 만들고
`GAMES` 배열에 추가하면 끝입니다.
