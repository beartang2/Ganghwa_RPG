# 설치 · 배포 가이드

카카오톡 단톡방 게임봇을 실제로 돌리는 방법을 단계별로 정리했습니다.
**공기계가 없어도** PC 에뮬레이터로 무료로 시작할 수 있습니다.

---

## 0. 개념 먼저 (중요)

카카오톡 **일반 단톡방은 공식 봇 API가 없습니다.** 그래서 봇을 돌리려면
"카카오톡에 로그인돼서 메시지를 읽고 답장하는 안드로이드 환경"이 **24시간 떠 있어야** 합니다.

- 봇이 도는 안드로이드 환경은 **딱 한 개**만 있으면 됩니다.
- 단톡방 **참여자**들은 아이폰·맥·안드로이드 아무거나 써도 됩니다. (봇이 도는 곳만 안드로이드면 됨)
- 봇 응답의 `@멘션`도 봇이 메시지 텍스트를 읽어서 반응하는 것뿐입니다.

> 📌 참고: 이름 옆에 공식 **[봇]** 뱃지가 붙은 카카오 ChatGPT 챗봇은 카카오가 서버에서
> 돌리는 별도 기능이라 기기가 필요 없지만, **커스텀 게임 로직을 넣을 수 없습니다.**
> 내 게임을 넣으려면 아래 메신저봇R 방식을 써야 합니다.

---

## 1. 봇을 돌릴 환경 고르기

| 방법 | 기기 | 비용 | 특징 |
|------|------|------|------|
| **A. 공기계 안드로이드폰** | 안 쓰는 폰 | 무료 | 가장 쉬움. 충전기 꽂아 24시간 |
| **B. PC 에뮬레이터** | PC | 무료 | PC 켜져 있을 때만 동작 |
| **C. 클라우드 안드로이드** | 없음(원격) | 유료 | 24시간, 전기·소음 무관 |

공기계가 없다면 **B. PC 에뮬레이터**로 시작하는 걸 추천합니다.

### B. PC 에뮬레이터 설치 (예: LDPlayer)

1. [LDPlayer](https://www.ldplayer.net/) 또는 블루스택 등 안드로이드 에뮬레이터 설치
2. 에뮬레이터 안에서 Play 스토어 로그인
3. 다음 단계(2번)로 진행

> 💡 PC를 끄면 봇도 멈춥니다. 항상 켜둘 수 없다면 **C. 클라우드 안드로이드**
> (예: 상시 켜지는 원격 안드로이드 인스턴스)를 고려하세요. 설정 방식은 에뮬레이터와 동일합니다.

### 🖥️ 맥(애플 실리콘 M1~M4)을 24시간 봇 서버로 만들기

메신저봇R은 안드로이드 앱이라 맥에서 직접 못 돌립니다. 대신 **맥 안에
안드로이드 에뮬레이터를 띄우고 맥을 24시간 켜두면** 맥이 봇 서버가 됩니다.
애플 실리콘에선 **안드로이드 스튜디오 에뮬레이터**가 ARM 네이티브로 가볍게
돌아가 서버 용도로 가장 적합합니다. (더 쉬운 GUI를 원하면 **BlueStacks Air** —
애플 실리콘 네이티브, 무료 — 도 가능하며, 설치 후 흐름은 동일합니다.)

**1) 안드로이드 스튜디오 + 가상기기(AVD) 준비**
1. [Android Studio](https://developer.android.com/studio) 설치 (무료)
2. 실행 → *More Actions* → **Virtual Device Manager** → **Create Device**
3. 기기: 아무 폰(예: Pixel 6) 선택
4. 시스템 이미지: **arm64-v8a** + **Google Play** 포함 이미지(예: API 34/35) 다운로드 후 선택
   - Google Play 포함 이미지여야 카카오톡을 스토어에서 바로 설치할 수 있습니다.
5. 이름 지정(예: `kakao-bot`) → Finish → ▶︎ 로 부팅

**2) 에뮬레이터 안에서 카카오톡 + 메신저봇R 설치**
1. Play 스토어 로그인 → **카카오톡** 설치 → **봇 전용 카카오 계정**으로 로그인 → 단톡방 초대
2. **메신저봇R** 설치 (스토어에 있으면 설치, 없으면 공식 APK를
   에뮬레이터 창에 드래그&드롭 하거나 `adb install 파일.apk`)
3. 메신저봇R 실행 → **알림 접근 권한** 허용 → 아래 "3. 봇 코드 넣기"로 진행

**3) 맥이 잠들지 않게 (24시간 유지)**
- 맥을 전원에 연결
- 터미널에서 `caffeinate -dimsu` 실행해두면 잠자기 방지 (창 닫지 말 것),
  또는 시스템 설정 → 배터리/에너지 → "디스플레이 꺼짐 시 자동 잠자기 방지" ON
- 에뮬레이터 창과 메신저봇R을 계속 켜둔 상태로 유지
- 에뮬레이터 안(안드로이드)에서도 메신저봇R의 **배터리 최적화 예외** 설정

**4) 게임 데이터 백업(선택)**
- 데이터는 에뮬레이터 안 `/sdcard/msgbot/game_rpg.json` 에 저장됩니다.
- 백업: `~/Library/Android/sdk/platform-tools/adb pull /sdcard/msgbot/game_rpg.json ./backup.json`

> ⚠️ 참고: 에뮬레이터는 RAM/CPU를 꽤 씁니다. 램 16GB 이상 맥을 권장하고,
> 안 쓰는 다른 앱은 닫아두세요. 맥을 끄거나 재우면 봇도 멈춥니다.

## 2. 메신저봇R 설치 & 봇 계정 준비

1. 안드로이드(공기계/에뮬레이터)에서 **메신저봇R** 설치
   - Play 스토어에서 "메신저봇R" 검색, 또는 공식 배포처의 APK 사용
2. **봇 전용 카카오 계정**으로 카카오톡에 로그인 (아래 "봇 전용 계정 만들기" 참고)
3. 메신저봇R 실행 → 안내에 따라 **알림 접근 권한** 등 필요한 권한 허용
   - 봇은 이 "알림 읽기 / 답장" 권한으로 동작합니다.

### 봇 전용 카카오 계정 만들기

카카오톡 계정은 **전화번호 1개당 1개**만 만들 수 있고, **모바일은 계정당
1기기만 로그인**됩니다. 즉 내 메인 계정을 에뮬레이터에 넣으면 내 폰 카톡이
로그아웃돼요. 그래서 봇은 **별도 번호로 만든 전용 계정**이 반드시 필요합니다.

1. **여분의 전화번호 확보** (관건)
   - 가장 확실: **알뜰폰 선불 유심**(월 몇천 원~) 개통해 새 번호 받기
   - 안 쓰는 가족 번호 중 카톡 미가입 번호가 있으면 그것도 가능
   - ⚠️ 070/인터넷전화 등 **SMS 수신이 안 되는 번호는 인증 불가**
2. **계정 생성 & 인증**
   - 에뮬레이터 카카오톡 → *새로 시작하기* → 새 전화번호 입력
   - **인증 문자(SMS)는 그 유심을 꽂은 폰에서 받아** 코드를 에뮬레이터에 입력
     (안드로이드 스튜디오 에뮬레이터는 실제 SMS 수신이 안 되므로, 실제 번호가
     필요합니다)
   - 카카오계정(이메일+비밀번호) 생성 → 닉네임을 `게임봇` 등으로 설정
3. **단톡방에 넣기**
   - 봇 계정을 에뮬레이터 카카오톡에 로그인 상태로 유지
   - 내 메인 계정으로 봇 계정을 **친구 추가 → 단톡방에 초대**

> 🔒 봇 자동화는 카톡 약관 위반이라 계정 제재 위험이 있습니다. **전용(버리는)
> 계정**을 써서 메인 계정을 보호하세요.

## 3. 봇 코드 넣기

1. 메신저봇R 상단 **＋** 버튼으로 새 봇(프로젝트) 생성 → 이름 지정 (예: `게임봇`)
2. 편집기 열기 → 기존 내용 지우고 이 저장소의 **`main.js`** 내용을 전부 복사해 붙여넣기
3. **저장** 후 **컴파일(▶)** — 오류 메시지가 없으면 정상
4. 봇 목록에서 해당 봇을 **ON**

---

## 4. 단톡방에서 확인

1. 봇 계정을 게임할 **단톡방에 초대**
2. 단톡방에 `도움말` 입력 → 명령어 목록이 오면 성공 🎉
3. `출석` → `강화` → `사냥` → `프로필` 순으로 테스트

### 특정 방에서만 반응시키기
`main.js` 의 `CONFIG.allowedRooms` 에 방 이름을 넣으세요.
```js
allowedRooms: ['우리 게임방'],
```

### 명령어 접두사 쓰기
다른 대화에 봇이 끼어드는 게 싫으면 접두사를 설정하세요.
```js
prefix: '/',   // 이제 "/주사위" 처럼 입력해야 반응
```

## 5. 자주 겪는 문제

| 증상 | 확인할 점 |
|------|-----------|
| 봇이 아무 반응 없음 | 메신저봇R **알림 접근 권한** 허용 여부, 봇 **ON** 여부 |
| 컴파일 오류 | `main.js` 전체를 빠짐없이 붙여넣었는지 확인 |
| 답장이 안 감 | 카카오톡 알림에서 해당 방 알림이 켜져 있는지 (알림 꺼지면 못 읽음) |
| 가끔 멈춤 | 에뮬레이터/폰 절전 모드 해제, 메신저봇R 배터리 최적화 예외 설정 |
| 특정 방만 반응시키고 싶음 | `CONFIG.allowedRooms` 설정 |

---

## 6. 주의사항

- 카카오톡 자동화는 비공식 방식이라 **과도한 메시지 전송 시 계정 제재 위험**이 있습니다.
  스팸성 자동 발송은 피하고, 게임 응답 위주로 사용하세요.
- 봇 계정과 참여자들의 개인정보·대화 내용 취급에 유의하세요.
